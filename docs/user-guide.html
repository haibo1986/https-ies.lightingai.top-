01 / OVERVIEW

这个工具是做什么的

一句话：把"已经实测的旧灯具"换算成"还没实测的新灯具"。

灯具厂家经常遇到这种情况：同系列产品只换了功率、LED 颗数或灯具长度，新规格还没来得及进光度实验室实测，但客户已经要配光文件做方案了。本工具解决的就是这个问题——

新灯具光通量 ───────── × 原光强数据 = 估算光强数据 原灯具光通量
上传一份真实测过的 IES 文件，填入新旧灯具的光通量与参数，工具按统一比例缩放整份光强矩阵，输出标注为 ESTIMATED 的 IES 文件和一份专业光度报告 PDF（配光曲线、等照度图、亮度限制、区域光通量、完整光强表等，页数随数据规模自适应）。未启用「配光对中校正」时，配光形状保持不变。

先认识这几个词

名词大白话解释
IES 文件记录「灯具向各个方向发出多少光」的文件，照明设计软件读它做计算
Type A / B / C三种记录方向的坐标方式，不代表精度等级；常见灯具多用 Type C。本工具三种都支持
相对 / 绝对光度相对光度：文件按每 1000lm 记录形状，光通量是文件头声明的值（可能是光源额定值）；绝对光度：文件直接记录灯具实测光强、不声明光通量，工具按光强积分估算总光通量
50% 光束角光强下降到该平面峰值一半时，两侧方向之间的夹角（不是「包含 50% 光通量」的角度）
TILT灯具倾斜安装时使用的光强修正数据；本工具仅支持 TILT=NONE（无倾斜修正）
C-Gamma 光强表按水平平面（C）和垂直角度（γ）排列的完整光强数据表，IES 的核心内容

为什么按光通量、不按功率算？

因为 LED 的光效、驱动效率和发热状态会随功率变化，电功率不能可靠代表光输出。按实测光通量的比例缩放，是可信度更高的做法——但即便如此，结果仍是"配光形状不变"这一假设下的估算。

适用与不适用

✅ 适用场景❌ 不适用（必须重新实测）
同系列灯具，仅功率或驱动电流变化光束角变化、透镜更换、反光杯或其他光学结构变化
LED 数量或密度变化，但透镜、角度和光学结构不变需要认证、招投标定版、工程验收、第三方检测或法律用途
灯具长度或模组数量变化，用于前期方案评估正式交付定版、验收或认证
PWM 调光或缺少目标光通量时的辅助估算—

本工具不提供的功能：DIALux / Relux / AGi32 场景计算、批量数据库管理、AI 配光预测、账号体系。但生成的估算版 IES 可以导入 DIALux、Relux、AGi32 做前期方案试算，不可用于最终设计定版、验收或认证。

风险等级怎么理解

等级含义处理方式
低风险配光形状基本不变，适合估算换算正常生成
中风险可能影响近场洗墙均匀性，仅供早期比较和方案试算可以生成，正式定版前必须实测验证
高风险光学结构改变，统一倍率无法得到可信结果禁止生成，必须重新实测
IMPORTANT

风险等级只反映所选变更类型，不代表估算误差大小——工具不会判断缩放倍率是否合理。产品同时发生多项变化时，应选择风险最高的一项；任何透镜、光束角或光学结构变化都不能用低风险选项规避。同理，「校验全部通过」只表示文件格式与内部计算一致，不表示目标灯具的真实光度性能已验证。

02 / QUICK START

快速上手（五步完成一次换算）

资料齐全、跳过可选增强时，基础换算通常几分钟可完成；首次使用估算器或 PDF 标定需要更长时间。第 4 步为可选增强，跳过也能生成。

1

上传并解析 IESSOURCE FILE

点击「选择 .ies 文件」选中原始实测文件，再点「上传并解析」，稍候页面会显示 IES 光度摘要。

  • 文件格式必须为 .ies，大小不超过 10MB
  • 标准版本仅支持 IESNA:LM-63-1995 和 IESNA:LM-63-2002，其他版本需先转换
  • 仅支持 TILT=NONE（不含倾斜修正数据）的文件
  • 支持 Type C、Type B、Type A 三种光度坐标；Type B/A 文件同样支持换算（详见 FAQ）
2

核对 IES 光度摘要CORE SUMMARY

上传成功后先核对这几项，确认文件没问题再往下填：

页面右上角的状态标签说明光通量从哪来：「可自动带入光通量」表示 IES 文件头填写了「灯数量 × 每灯光通量」，工具用这个乘积预填。注意：对相对光度文件，这个值可能是光源额定光通量，不一定等于灯具实测总光通量。换算倍率的分母必须与「目标灯具总光通量」口径一致，请用与该 IES 对应的测试报告核对，以灯具实测总光通量为准，只有确认一致时才可直接采用。* 该字段就是「IES 声明光通量」，不是实测值。

「已用积分估算预填」表示是绝对光度文件，光通量由工具按光强矩阵数值积分估算而来，请与实测值核对后再用；「需手动填写光通量」表示文件数据不足以估算，需自行填写。

可点击展开「IES 原始技术参数」查看版本、TILT、光度类型、采样角度、倍率与灯具尺寸等原始字段，供技术人员核对。

变更类型风险说明

配光对中校正（可选勾选）：把各平面配光曲线按自身峰值平移至正下方（γ=0°）。注意：勾选后会实际改写 IES 光强矩阵，不再是单纯的按光通量等比例缩放；当原文件角度范围有限、偏移较大时，可能丢失边缘方向数据，工具会做光通量补偿。仅在确认「灯具本应正下出光、偏移来自测试未对中」时使用，并在生成后核对结果页的「对中校正」提示。仅适用于非偏光设计的灯具；洗墙灯等偏光配光请勿勾选。工具会检测当前文件峰值方向并给出建议。

AUTOSAVE

浏览器会自动保存：目标型号、目标功率、目标光通量、发光面尺寸、变更类型、报告补充字段和估算器输入，刷新页面或下次打开仍在。但不会保存：原始光通量（换文件时会按新文件重新预填）、对中校正勾选、已上传的 IES/PDF、人工 PDF 标定、Logo 和生成结果——刷新或重新打开后，需重新上传 IES 并核对上述内容。

03 / FLUX ESTIMATOR

估算器：不知道目标光通量？

按 LED 颗数、电流曲线、模组或调光状态自动算出目标光通量，并实时同步到表单。

展开「不知道目标光通量？」估算器，第一步先回答：你改变了什么？

场景需要提供的数据适用情况
调整 LED 电流原始 / 目标单颗电流 + 电流—相对光通量曲线颗数不变，只调驱动电流
调整 LED 颗数原始 / 目标颗数 + 原始发光长度单颗电流不变；目标发光面尺寸取上方主表单填写值
颗数和电流都变以上两类的数据都要同时改颗数与电流
灯具长度 / 模组变化原始 / 目标模组数量相同结构重复扩展，自动更新 IES 发光尺寸
PWM 调光原始 / 目标 PWM 占空比DALI、0–10V、智能调光、日夜模式或应急模式（峰值电流不变）
按功率和光效估算预计目标光效（lm/W）缺少 LED 数据时的备用方式，低置信度

3.1提供 LED 电流—光通量数据（三种方式任选）

方式操作
选常用型号从「常用 LED 型号」下拉选择，自动填入曲线；常用型号也可以自己存（见下）
粘贴或导入文件文本框直接粘贴，每行一个数据点：电流 mA, 相对光通量 %。例如 700,170 表示 700mA 时相对光通量为基准值的 170%，不是 170 lm；或导入 Excel（.xlsx/.xls，读第一个工作表前两列）、CSV、TXT
曲线截图取点只有产品规格书上的曲线图片？上传 PNG/JPG/WebP 截图，半自动取点（图片只在浏览器本地处理，不上传）

3.2曲线截图取点怎么操作（四步）

  1. 先按图面刻度填写四个轴范围（X 轴最小/最大值 mA，Y 轴最小/最大值 %）
  2. 点击坐标图左下角的 0/0 交点（标定原点 O）
  3. 点击右下角 X 轴最大刻度点，再点击左上角 Y 轴最大刻度点
  4. 沿曲线点击 5–12 个数据点，软件自动换算成「电流 mA、相对光通量 %」；采好的点可在列表里直接修正或删除，确认后导入估算器
TIP

前三次点击都是坐标轴位置，不是曲线数据点。软件会检查 O–X 是否水平、O–Y 是否垂直，标定错误时会提示，不会进入取点阶段。

3.3估算结果怎么用

  • 右侧实时显示估算目标光通量、建议范围与置信度（高 / 中等 / 低）
  • 有效结果会自动同步到主表单（目标光通量、原始光通量、变更类型），无需手动抄写
  • 可填「基准点电流 + 光通量」（例如 300mA 时 218lm）：未填原始实测总光通量时，工具用它直接计算灯具总光通量；已填时按比例路径计算，基准点不参与
  • 散热与结温条件可选「与原灯具基本相同 / 未知」；透镜与光学结构可选「完全不变 / 仅材料透过率变化（需填透过率%）/ 结构变化」
  • 配好一组曲线可点「存为常用型号」，下次从下拉直接选。注意：常用型号保存在服务器公共库（不在浏览器里），其他使用者可能看到，请勿存入敏感数据

04 / SOURCE PDF

原始 PDF 溯源（可选）

上传原始光度测试报告，用于数据核对，识别成功还可生成一份「原报告版式叠加参考件」。

在「原始光度测试 PDF」区域上传原厂测试报告（≤20MB）。原文件不会被修改，不传也不影响生成。

上传后发生什么说明
版式自动识别（如惠谱 CPM-1800B 版式）自动提取报告字段供核对，并额外生成一份在原报告版式上叠加估算数据的参考件（只更新已适配的字段区域）
版式无法自动识别可人工标定：在报告首页依次框出 5 个字段（灯具型号、输入功率、总光通量、光效、最大光强），完成后生成叠加参考件——只替换这 5 个框选字段，其余页面仍是原灯具内容
识别值的作用只用于核对与版式叠加，不会覆盖目标 IES 的计算结果；标准报告始终以目标 IES 和补充表单为唯一数据源
IMPORTANT

叠加参考件不是完整重算报告：人工标定只替换首页框选的 5 个字段，自动识别也只更新已适配区域，其余页面的曲线、表格和文字仍保留原灯具内容。生成后必须逐页核对，不得单独作为目标型号的正式或完整光度报告发送。计算结果以标准估算报告和估算版 IES 为准。

NOTE

标准版专业报告始终由目标 IES 统一生成（页数随数据规模自适应），叠加参考件是识别成功后的附加可选交付物，叠加失败不影响标准报告。

06 / RESULT CENTER

结果与文件中心

生成后自动滚动到结果中心，分三个标签页。

6.1IES 预览

  • 顶部显示缩放比例、风险等级与校验状态；确认「校验：全部通过」再下载。校验只检查文件格式与内部计算一致性，不代表目标灯具的真实光度性能已验证
  • 目标型号 / 功率 / 光通量 / 最大光强四项指标供核对
  • 「文件检查」逐项列出校验结果：完整报告约 22 项，简化报告（部分 Type A/B）约 11 项，数量随报告模式变化，少于 22 项不是异常；配光曲线应与原文件形状一致、仅幅值按比例变化
  • 必要时展开「IES 原始文本」（前 120 行）做技术核对

6.2报告预览

07 / FAQ

常见问题

IES 自动带入的光通量与测试报告不一致，以哪个为准？

以与该 IES 对应的测试报告中的灯具实测总光通量为准。IES 里「可自动带入」的值是文件头填写的「灯数量 × 每灯光通量」，对相对光度文件可能是光源额定光通量，不等于灯具实测总光通量。换算倍率的分母必须用实测总光通量，口径不一致会导致整个光强矩阵按错误倍率缩放。

绝对光度文件的光通量要自己填吗？

IES 未声明光通量时，工具会按光强矩阵数值积分估算并预填一个值。这个值是估算的，请与实测报告核对后使用；如无法积分则需手动填写。

Type B / Type A 文件能用吗？有什么区别？

能用。光通量缩放对任意光度坐标都正确，输出 IES 保持原坐标。区别在报告：工具会在角度覆盖足够时把 Type A/B 转换为 Type C 后分析（配光分析按 Type C 约定展示，仅供参考）；角度覆盖不足时生成简化报告，仅含参数摘要、原始光强数据表和使用声明，没有配光曲线、光束角、等照度、亮度限制和区域光通量。Type A/B 的光束角按 H≈0 剖面「半峰值全宽」（即 50% 光强光束角）计算。

为什么有些变更类型不能生成？

光束角、透镜、光学结构变化会改变配光形状，统一倍率缩放得不到可信结果，工具会拦截并提示「必须重新实测」。这不是 bug，是防止发出错误数据。

中风险可以继续生成吗？

可以，但仅供早期比较和方案试算。LED 数量/密度或灯具长度变化可能影响近场洗墙均匀性，正式定版前必须实测验证，不能凭中风险结果定稿或验收。

为什么校验全部通过，仍然不能用于验收？

「校验全部通过」只表示文件格式和内部计算一致，不表示目标灯具的真实光度性能已验证。工具的核心假设是「配光形状不变、按光通量等比缩放」，它无法预测真实的光学、热学差异，结果始终是 ESTIMATED 估算值。

缩放倍率很大时还能用吗？

工具不设合理性上限，任何正数倍率都会照算。但倍率偏离越大，与真实产品性能的偏差通常也越大。缩放前请先判断目标灯具是否真的只是「同结构、按比例变化」——如果倍率意味着光学结构都要改，那就该重新实测。

为什么按光通量比、不按功率比缩放？

LED 光效、驱动效率、热状态都随功率变化，电功率不能可靠代表光输出；实测光通量的比例更接近真实光输出关系。即便如此，结果仍是「配光形状不变」假设下的估算。

上传失败常见原因有哪些？

① 不是 .ies 后缀；② 文件超过 10MB；③ 文件含 TILT=INCLUDE / TILT=FILE（仅支持 TILT=NONE）；④ 标准版本不是 LM-63-1995 / LM-63-2002；⑤ 文件结构不完整，解析被拒。报错信息会说明具体原因。

生成过程中刷新了页面怎么办？

刷新或关闭页面后，当前上传记录和结果页会丢失，不能依赖后台继续完成。请重新上传 IES，核对原始光通量、对中校正勾选等未自动保存的内容后，再重新生成。

隔天回来下载提示「文件不存在」？

服务器文件不是长期存储：超过 24 小时的文件会在后续上传或生成时被清理，24 小时也不是精确删除时点；服务重启同样会使上传记录失效。重新上传 IES 再生成一次即可，生成后请立即下载归档。

刷新后哪些内容会保留、哪些要重来？

自动保留（浏览器本地）：目标型号、目标功率、目标光通量、发光面尺寸、变更类型、报告补充字段、估算器输入。不保留、需重来：已上传的 IES / PDF、原始光通量（按新文件重新预填）、对中校正勾选、人工 PDF 标定、Logo、生成结果。换浏览器或清除浏览器数据，自动保留的部分也会丢。

客户模板和常用 LED 型号存在哪里？别人能看到吗？

两者都保存在服务器公共库（不是浏览器），多人共享部署下其他使用者可能看到模板内容。请勿保存敏感客户信息或保密数据；表单草稿只保存在当前浏览器。

报告页数为什么每次不一样？

页数随数据规模自适应。普通 Type C 报告按原始角度数据展示光强表；Type A/B 转换报告的数据表按约 γ5°×C15° 抽样以控制页数（完整输出以生成的 IES 为准）；简化报告页数更少。同一文件生成结果应一致。

标准报告和「原版式报告」是什么关系？

标准报告始终由目标 IES 生成，是主要交付物。「原版式报告」是把估算数据叠加到原始测试报告版式上的参考件——只替换人工标定的 5 个字段或自动识别的适配区域，其余页面仍是原灯具内容，不是完整重算报告。须逐页核对后与标准报告配套使用。

配光对中校正要不要勾？

非偏光设计的灯具，若最大光强方向偏离正下方（γ 超过 1°），可考虑勾选。注意它会实际改写 IES 光强矩阵（不再是单纯等比缩放），角度范围不足时可能丢失边缘方向数据。仅在确认「灯具本应正下出光、偏移来自测试未对中」时使用，生成后核对结果页的对中提示。洗墙灯等偏光配光不要勾。
